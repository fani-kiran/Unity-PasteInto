# Unity-PasteInto
Copy object and past into multiple object as chaild. 

# Installing
Copy Pasteinto.cs in to Editor folder.
Refresh by pressing Command+R / Control+R

# How to use
Select the object/prefab in Hierarchy/Project window.
From Edit menu select "Copy for PasteInto".
<img width="337" height="63" alt="Copyfor" src="https://github.com/user-attachments/assets/6e5fad70-fb1b-44d5-9e94-9a8cdf158997" />

Select multiple object in Hierarchy
From Eidt menu select "Paste Into".
<img width="342" height="61" alt="Pasteinto" src="https://github.com/user-attachments/assets/93a891ac-f84b-4d8a-bc2f-969d085a62d9" />

Copied object will be added as chaild object under all selected objects.

# Note
It will **not** work with regular copy command.
